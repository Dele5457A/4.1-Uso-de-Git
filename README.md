# Tienda UTNG

Proyecto de Programación Orientada a Objetos para la gestión de productos mediante Java, JDBC y pgAdmin 4.

## Funciones
- Agregar producto
- Buscar producto por ID
- Listar productos
- Actualizar producto
- Eliminar producto

## Tecnologías
- Java 17
- Maven
- JDBC / MySQL
- JavaFX
- Git / GitHub
