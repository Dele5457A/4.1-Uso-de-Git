# Tienda UTNG - Sistema de Gestión de Productos

Sistema desarrollado en JavaFX para el control de inventario de productos.

## Estructura del Proyecto
- **Modelo:** `Producto.java`
- **Conexión:** `ConexionDB.java`
- **Acceso a Datos:** `ProductoDAO.java` / `ProductoDAOImpl.java`
- **Servicios:** `ProductoService.java`
- **Interfaz:** Controladores JavaFX y vistas FXML.

## Requisitos
- Java 17 o superior
- MySQL
- Maven
